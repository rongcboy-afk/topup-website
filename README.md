# C-Boy Store

A front-end demo for a Cambodian gaming/digital top-up storefront.

## Files
- `index.html` — structure and content
- `style.css` — responsive premium UI
- `script.js` — products, cart, demo checkout, localStorage order tracking

## Run
Open `index.html` in a modern browser. No build step is required.

## Before production
1. Replace demo prices and stock in `script.js`.
2. Replace the QR placeholder with your actual payment provider/QR.
3. Connect checkout/order creation to a secure backend.
4. Never put private payment/API secrets in frontend JavaScript.
5. Replace contact placeholders with the store's real channels.
6. Confirm you have authorization to sell/fulfill each digital product and subscription.
